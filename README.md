# GL FIXCORE - Sitio web

Abre la carpeta en Visual Studio Code y haz clic derecho en `index.html` > "Open with Live Server"
(extensión Live Server), o simplemente abre `index.html` con tu navegador.

## Qué editar
- WhatsApp: `js/main.js` (arriba, objeto CONFIG)
- Juegos: `js/games.js` (una línea por juego; imágenes en `images/games/`, ver instrucciones al inicio del archivo)
- Fotos de servicios: `images/services/` (reparacion.jpg, mantenimiento.jpg, modificacion.jpg)
- Foto de fondo del inicio (opcional): `images/hero/fondo.jpg`
- Textos (Sobre nosotros, servicios, dirección): `index.html`
- Redes sociales: busca `aria-label="Instagram"` etc. en `index.html` y cambia `href="#"`
- Colores y fuentes: variables al inicio de `css/styles.css`
